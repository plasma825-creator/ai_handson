# カコク大からの脱出 ～旭台キャンパス編～

生成AI研修「カコク大からの脱出 ～旭台キャンパス編～」用の静的HTMLサイトです。  
HTML / CSS / JavaScriptのみで動作します。

## 概要

架空大学「金沢国際酪農大学 旭台キャンパス」を舞台に、国立大学事務を想定した生成AIハンズオンを行います。
参加者は3つのミッションをクリアし、最後に解放されるFINAL MISSIONで脱出キーワードを入力します。

## 想定環境

- ブラウザ：Microsoft Edge等
- 生成AI：Microsoft Copilot等
- Teams投稿や添付ファイルを併用する想定
- サーバー、DB、ビルド環境は不要

## ファイル構成

```text
index.html   研修ポータル本体
style.css    画面デザイン
script.js    進捗管理、FINAL解放、脱出判定、成功カード表示
README.md    このファイル
```

MISSION 3で使用する次のファイルは、必要に応じて `index.html` と同じフォルダに配置してください。

```text
照会回答整形ツール.xlsm
Formから_照会回答.csv
```

## HTML上の表示方針

各ミッションのカードは、参加者が画面上で見る情報に絞っています。

- ストーリー
- やること
- ヒント（折りたたみ）
- Extra MISSION（折りたたみ）

Teams投稿文、設計書上の目的、想定所要時間、研修上のねらい等は、HTMLには原則表示しません。

## ミッション構成

### MISSION 1：異国からのSOS

中国語で届いた問い合わせメールを、生成AIで整理するミッションです。

HTML上の「やること」は以下の2点です。

- メール本文の日本語要約を作成する
- 問い合わせ事項を箇条書きで整理する

メール本文はTeams添付を主とし、HTML上では補助として折りたたみ表示しています。
署名削除や個人情報の扱いは、やること本体ではなく注意・ヒントとして扱います。

### MISSION 2：鶴の一声

学生募集ポスターに使う画像案を生成AIで作成するミッションです。

生成画像には、次の3条件を必須としています。

- 牛乳を飲んでいる人物
- 建物
- 牛

画像内の文字入れは不要です。文字は後からPowerPoint等で入れる想定です。

### MISSION 3：前任者の遺産

前任者が残した半自動Excelツールを、Copilot等で読み解きながら提出用ファイルを作成するミッションです。

HTML上には「使用ファイル（補助）」として次のファイル箱を用意しています。

- `照会回答整形ツール.xlsm`
- `Formから_照会回答.csv`

実ファイルを同じフォルダに置くと、リンクとして使用できます。

### FINAL MISSION：謎のメッセージ

MISSION 1〜3をすべて「済」にすると初めて表示されます。  
初期状態ではFINAL MISSIONの存在は画面上に表示しません。

参加者は、理事から届いた謎の英数字の羅列を生成AIに解析させ、脱出キーワードを取得します。  
HP上の入力欄に正しいキーワードを入力し、「脱出」ボタンをクリックすると成功カードが表示されます。

ヒントでは「Base64」とは明示せず、「暗号」「変換された文字列」程度の表現にしています。

## 進捗管理

- MISSION 1〜3のみを進捗対象とします。
- 進捗表示は `0 / 3 完了` 形式です。
- チェック状態はブラウザの `localStorage` に保存されます。
- 「進捗をリセット」ボタンで保存状態を初期化できます。

## FINAL MISSIONの動作

- MISSION 1〜3がすべて済になると、FINAL MISSIONカードが表示されます。
- 脱出キーワードの正誤判定はJavaScriptで行います。
- 正解時は画面上部へゆるやかにスクロールし、中央に成功カードをフロートアップ表示します。
- 成功カードは右上の閉じるボタン、背景クリック、Escキーで閉じられます。

## 配置方法

1. ZIPを展開します。
2. `index.html`、`style.css`、`script.js` を同じフォルダに置きます。
3. MISSION 3のExcel・CSVを使う場合は、次の2ファイルを同じフォルダに置きます。

```text
照会回答整形ツール.xlsm
Formから_照会回答.csv
```

4. `index.html` をブラウザで開きます。

学内HP等に配置する場合も、同じフォルダ構成を保ってください。

## 注意事項

- 本サイトは研修用の静的HTMLです。
- セキュリティを目的とした仕組みではありません。
- 脱出キーワードや謎メッセージは、ソースを詳しく見れば確認できます。
- 研修上は、参加者が通常の画面導線に沿って生成AIを使うことを想定しています。

## 更新メモ

- FINAL MISSIONは未解放カードを表示せず、MISSION 1〜3完了後に初めて表示する仕様です。
- FINAL MISSIONのExtra MISSIONは削除済みです。
- MISSION 1のメール本文とFINAL MISSIONの謎メッセージは、補助情報として折りたたみ表示しています。
- MISSION 2の生成画像には「牛乳を飲んでいる人物」「建物」「牛」を必須条件として追加済みです。
- MISSION 3には使用ファイル用の箱のみを追加済みです。実ファイルは別途配置してください。
