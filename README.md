# 生成AI活用研修「カコク大からの脱出 ～旭台キャンパス編～」

静的HTML/CSS/JSのみで動く研修ページです。GitHub Pages等にそのまま置けます。

## ファイル構成

- `index.html`：研修ページ本体
- `style.css`：見た目
- `script.js`：カードクリック時の完了表示、進捗保存

## 使い方

1. このフォルダ一式をGitリポジトリに置く
2. GitHub Pages等で公開する
3. 参加者にURLを案内する

## 仕様

- ミッションカードをクリックするとカードが沈み、左上に「済」マークが出ます。
- 進捗はブラウザの `localStorage` に保存されます。
- 「進捗をリセット」で初期状態に戻せます。
- FINAL MISSION用の理事メッセージは `index.html` 冒頭のHTMLコメント内に隠しています。
